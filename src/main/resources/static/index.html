IF Eventos

Uma aplicação para aprender sobre APIs, inscrições e formatos de dados.

Início Usuários Eventos Inscrições

Como usar

  1. Cadastre uma pessoa em Usuários.
  2. Crie um evento em Eventos.
  3. Vincule a pessoa ao evento em Inscrições.
  4. Na lista de eventos, exporte os participantes em JSON ou XML.

Consulte o README do projeto para conhecer as rotas da API e comparar os formatos exportados.
